# Security Policy

## Reporting Security Issues

Do not open a public issue for security-sensitive reports.

If you find a security issue in this scaffold, contact the maintainers privately through GitHub repository security advisories when available, or by using a private maintainer contact published for the project.

## Scope

Security-sensitive areas include:

- plugin permissions and marketplace governance
- scripts that copy, install, validate, or execute files
- dependency and CI changes
- data and privacy guardrails
- adapter behavior that could expose repository data

## Handling

Maintainers should acknowledge security reports, investigate impact, prepare a fix, and publish remediation notes when appropriate.

Unknown security facts must be marked `UNKNOWN` rather than inferred.
