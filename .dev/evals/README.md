# Evals

These evals describe vendor-neutral scenarios for assessing whether an agent follows the repository contract.

They are not tied to any AI provider, model, runtime, or marketplace. Each eval should be runnable by humans or by future tooling that reads scenario, expected behavior, and guardrails checked.

## MVP Scope

- Code review behavior.
- Test quality behavior.
- Architecture review behavior.

## Future Work

- Add repository-specific eval fixtures once application code exists.
- Add automated scoring only after the contract stabilizes.
